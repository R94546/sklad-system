# Выпуск обновлений Sklad Desktop

Приложение обновляется на **двух уровнях**:

## 1. Веб-часть (UI, страницы) — обновляется сама

Десктоп-приложение загружает прод-сайт `https://sklad-web-app.vercel.app`.
Любой деплой `sklad-web` на Vercel сразу виден в приложении — **ничего пересобирать не нужно**,
пользователь просто открывает приложение и видит новую версию.

## 2. Оболочка (.exe) — авто-обновление через GitHub Releases

Нужно только когда меняется сам `main.js` или версия Electron.
Установленные копии проверяют GitHub Releases при запуске и раз в 6 часов,
скачивают новую версию и предлагают перезапуск.

### Как выпустить новую версию оболочки

1. Поднять версию в `package.json` (`"version": "1.0.1"` → `1.0.2` и т.д.).
2. Задать токен GitHub (Personal Access Token с правом `repo`) в текущей сессии:
   ```powershell
   $env:GH_TOKEN = "ghp_ВАШ_ТОКЕН"
   ```
   Токен создаётся тут: https://github.com/settings/tokens (classic, scope `repo`).
3. Собрать и опубликовать:
   ```powershell
   cd sklad-desktop
   npm run release
   ```
   Команда соберёт `Sklad Setup X.Y.Z.exe` + `latest.yml` и зальёт их
   в **черновик релиза** на GitHub (`R94546/sklad-releases` — публичный репозиторий только для бинарников; исходный код в приватном `sklad-system`).
4. Открыть https://github.com/R94546/sklad-releases/releases, найти черновик и нажать **Publish release**.

После публикации все установленные приложения сами подтянут обновление.

### Важно

- **Версия в релизе должна быть выше установленной** — иначе обновление не предложится.
- **Релизы лежат в публичном `sklad-releases`** — клиенты качают обновления без токена. Исходный код остаётся приватным в `sklad-system`.
- Подпись кода (code signing) не настроена — авто-обновление работает, но Windows SmartScreen
  при установке может показать «Неизвестный издатель». Чтобы убрать — нужен платный сертификат.
- Локальная сборка без публикации: `npm run build` (создаёт `.exe` и `latest.yml` в `dist/`).
